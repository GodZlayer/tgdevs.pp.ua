# Site oficial — NewDuel AFK Adventure

Site estático pronto para GitHub Pages, Cloudflare Pages, Netlify ou hospedagem convencional.

## Páginas

- `index.html`: apresentação do jogo.
- `privacy-policy.html`: URL para a Política de Privacidade na Play Console.
- `terms.html`: Termos de Uso.
- `support.html`: URL pública de suporte.
- `data-deletion.html`: instruções de exclusão dos dados locais.
- `404.html`: página de erro.

Antes da publicação, substitua o e-mail `suporte@tgdevs.com.br` se necessário. Se o jogo ganhar login, anúncios, compras, analytics ou conexão com servidor, revise a política antes de publicar a atualização.
